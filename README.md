# Tournament Management System

A frontend-based tournament management system for floorball tournaments. The project was started in 2025 and has been continuously developed and refined throughout 2026.

## Features

* Automated group standings
* Automatic calculation of points and goal difference
* Automatic match results and rankings
* Calculates the playoff matchups based on group results
* Clear overview of teams, matches, and standings

## Technologies

* HTML
* CSS
* JavaScript

## About

The project was created to simplify the management of a floorball tournament by automating results, standings, and playoff progression.

It is currently a frontend project using static data and focuses primarily on functionality, structure, and user interface.

**Status:** Ongoing project
